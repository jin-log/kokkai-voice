# ショート動画構成（政治now. 運用ルール）

ソース（根拠の置き方）:
- **YouTube 公式 Analytics** の視聴維持率・平均視聴時間・スワイプ離脱を正とする（投稿後に必ず見る）
- 業界の一般知見（フックは冒頭数秒・Shorts は60秒未満）は補助。固有名詞の未検証ベンチマークは根拠にしない
- 自チャンネルの集計が溜まったら「自社運用実績（本数・集計期間）」に差し替える

---

## フック（0〜2秒）— 最重要

スワイプ判断の窓は**約3秒**。ただしフック本体は**2秒以内**に収める方が平均視聴時間で有利。

### 確定型（優先順）

| 優先 | 型 | 例 | 政治now.適性 |
|------|----|----|------------|
| 1 | **数字クレーム** | 「稼いだ47%が消える」 | ◎（統計記事） |
| 2 | **矛盾・逆張り** | 「給料上がっても豊かにならない」 | ◎（政治全般） |
| 3 | **好奇心ギャップ** | 「誰も教えてくれなかった理由」 | △（単体では弱い） |
| 4 | **リスト予告** | 「押さえる3点」 | ○（量産向け） |
| 5 | 質問単体 | 「なぜ少子化は止まらない？」 | ✕（単体NG） |

**ルール:**
- 質問を使うなら必ず数字か矛盾とセットで出す
- 1文・8〜12語（テロップ）
- テロップに数字が入るだけで滞留率が上がる（fact-check reflex）

### フック禁止

- 「みなさん〜」「今回は〜」などの前置き
- コンテキスト説明（「国民負担率とは〜」）から始める
- 曖昧な好奇心だけ（「信じられない結果が…」）
- 4秒以上かけて本題に入る

## カット数・ペース（確定値）

| 区間 | CPS（カット/秒） | テロップ1枚の尺 |
|------|----------------|---------------|
| フック 0〜3s | 0.7〜1.0 | **1〜1.5秒** |
| ボディ 3〜35s | 0.3〜0.5 | **2〜3秒** |
| CTA 最後3〜5s | 0.2〜0.3 | **3〜5秒** |

5枚で60秒 = 論外。短い尺でもテロップ変化は密に（目安: 30秒帯なら20枚前後）。

---

## 尺（診断ルール・固定推奨なし）

尺は「30〜40秒が正解」と決め打ちしない。**完走率（平均視聴時間 ÷ 動画尺）**で採用を決める。

### 運用

1. **初期テスト:** 同一テーマで **20〜30秒版** と **30〜40秒版** を作り、完走率を比較する
2. 完走率 **50%未満** の尺は採用しない（切る／再構成）
3. **チャンネル初期**（登録者少・データ薄い）は **20〜30秒を優先**
4. 完走率が安定してから 40秒帯の拡張を検討する

### 構成スケルトン（尺に合わせて伸縮）

```
[Hook]    0〜2s   ← フック本体は2秒以内（スワイプ窓は約3秒）
[Bridge]  直後    ← フックの約束を一言で確認
[Body]    中盤    ← 最大3ポイント。5〜8秒ごとにテキスト変化
[Payoff]  終盤前  ← フックの答えを明確に出す
[CTA]     最後    ← 2秒以内
```

### 横展開テンプレ（確定・shohizei-genmen）

採用済みの制作標準。次案件もこの型で作る。

- **テロップ分割:** 1行1枚。フックは2枚（数字→矛盾）。ボディも約2秒台で刻む
- **素材:** トピック関連のみ（`SLUG_BEAT_CLIPS` 手指定）。夜景・森など無関係ストック禁止
- **生成:** `npm run short:generate -- --slug <slug> --tempo 1.35` → 確認 → `short:upload`
- **正本ビート:** `scripts/lib/short-beats.mjs` の `F1_BEATS[slug]`

**鉄則:**
- 1動画1アイデア（支持ポイント最大3つ）
- 8秒以上ビジュアル（テキスト）変化なし → 離脱
- 中盤でコアメッセージを再確認する

## 投稿後の診断フィードバック（必須ループ）

1本出すたびに Analytics を見て、次本に反映する。

| 条件 | 打ち手 |
|------|--------|
| **スワイプ率 < 60%** | 冒頭1〜2秒（映像・テロップ・音声）を作り直す |
| スワイプは合格 ＆ **維持率 < 70%** | 離脱グラフの「崖」箇所を特定 → そこを削る／組み替える |
| 維持は合格 ＆ **エンゲージ低** | CTA不足、または末尾に「問い」がない |
| 指標は合格 ＆ **再生が伸びない** | 投稿頻度・母数不足（コンテンツ問題ではない） |

定義の目安（YouTube Analytics）:
- スワイプ率 ≈ 冒頭数秒で残った割合（視聴維持の初速）
- 維持率 ≈ 視聴維持率（Audience retention）
- 完走率 = 平均視聴時間 ÷ 動画尺
- エンゲージ ≈ 高評価・コメント・共有の反応密度

## テロップ設計

- 1枚 **全角14字以内**（既存ルール維持）
- 数字・固有名詞は単独カードに切り出す
- 「56年で」「1970年→」のように変化を見せる
- 音声なしで論点が分かること

### テキストサイズ（1080×1920 Shorts基準）

| 種別 | 最小サイズ | 備考 |
|------|-----------|------|
| 数字（number） | **140px以上** | ハイライト色必須 |
| 本文（text） | **90px以上** | 64pxは小さすぎる |
| 補助（sub/year） | **50px以上** | グレー系で階層を出す |

## 背景動画の選び方（確定ルール）

**大原則:** クリップの「感情トーン」がスライドの内容と一致すること。  
**必須:** `data/short-stock-clips.json` の保有ストックから選ぶ。各スライドで別クリップ（同一連発禁止）。

| クリップ | 感情・トーン | 使うスライド |
|---------|------------|------------|

| `supermarket-aisle-blur-vert` / `supermarket-shopper-mask-vert` | 家計・物価 | 物価高・食料・実感額 |
| `gas-station-neon-anime-vert` | 燃料 | ガソリン税・燃料対策 |
| `newborn-sleeping-vert` | 子育て | 子育て手当・少子化 |
| `tokyo-gov-sakura-vert` | 自治体 | 地方交付金・都政 |
| `diet-building-front-vert` / `diet-exterior-day-vert` | 権威・制度 | 政策・制度・フック |
| `politician-speech-vert` | 緊張・政治 | 国会発言/追及 |
| `report-chart-hand-vert` / `stock-chart-neon-vert` / `global-markets-globe-vert` | データ | 試算・不明点・市場 |
| `flag-waving-vert` | 国家・統計 | 国全体の話 |

### 動画モーション要件

- フックの背景は **ズーム or パン** が入るクリップ優先（静止は×）
- 各スライドで **異なるクリップ** に切り替える（パターンインタラプト）
- `hookZoom=true` は常時ON（既存実装）
- 背景クリップは **loop**（尺不足で黒落ちさせない）

## BGM（確定ルール）

- 映像尺より BGM が短い場合は **必ずループ**（`stream_loop -1`）
- フェードアウトは **映像終端 −1.5秒** から。固定秒（例: 18秒）での打ち切り禁止
- 実装: `scripts/lib/short-bgm.mjs` の `mixBgmIntoVideo`

## CTAカード（テンプレ・確定）

```
これ、あなたはどう思う？
コメント欄で教えて
記事の全貌はコメント欄のURLから
[+ ロゴ]
```

- `question`: 「これ、あなたはどう思う？」
- `endHint`: 「コメント欄で教えて\n記事の全貌はコメント欄のURLから」
- `endNarr`: 上記を自然な口語で1〜2文

### 完成報告（違反＝未完了）— 順番厳守

ショート完成時、チャット**先頭**に必ず書く。パス文字列だけ・「フォルダにある」は禁止。

1. **ローカル再生リンク（最優先）** — `file:///C:/Users/bero1/Projects/kokkai-voice/output/shorts/.../*.mp4` を Markdown リンクで全本
2. **案件ページURL** — `https://seiji1192.site/case/{slug}/`
3. **固定コメント文** — URL入り全文をコードブロック

正本ルール: `.cursor/rules/short-local-link.mdc`（alwaysApply）  
実装: `scripts/lib/short-comment-cta.mjs` / `youtube-upload-draft.mjs`

## 適用例（国民負担率・20〜30秒帯の一例）

```
[0.0〜1.5s] 稼いだ47%が消える

[3.0〜5.0s] 2倍になった原因は税金じゃない
[5.0〜7.0s] 社会保険料

[8.0〜9.5s] 1970年：5.4%
[9.5〜11s]  2024年：18.5%

[12〜14s]  コロナの年
[14〜16s]  所得の62%が消えた

[17〜19s]  国会では
[19〜21s]  「少子化の原因」と追及

[22〜25s]  56年分の全データ
[25〜27s]  seiji1192.site ↓
```

27秒・12枚。初期はこうした短尺例を優先し、完走率で長い版の可否を判断する。
